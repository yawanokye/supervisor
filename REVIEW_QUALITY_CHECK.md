# Review quality before wider release

Use real, consented or anonymised examples from quantitative, qualitative and mixed-methods work. Include adequate passages as well as passages with known faults. Keep a supervisor’s independently prepared findings as the reference. Run each candidate model with the same source, scope and settings.

For at least 25 released comments per model, score each dimension from 1 to 5:

| Dimension | What the supervisor checks |
| --- | --- |
| Accuracy | The identified weakness exists in the supplied work. Valid methods or values are not treated as errors. |
| Evidence | The quotation and location support the diagnosis. No invented source, result or claim appears. |
| Usefulness | The student can make a specific correction without guessing what the reviewer means. All linked actions survive. |
| Certainty | Direct errors receive direct corrections. Uncertain interpretations receive an appropriate verification request. |
| Voice | Comments use natural wording, varied openings and suitable sentence lengths. Questions and praise appear only when useful. |
| Independence | Comments address distinct issues. Repeated instances are consolidated with clear correction scope. |

Also record missed material weaknesses, false positives, repeated openings, comments requiring clarification, latency, token usage and estimated cost. The internal full issue ledger must agree with the readiness decision even when the margin-comment shortlist is shorter.

Inspect the native Word and inline copies, not only JSON output. Check tables, merged cells, paragraph anchors, recurring corrections and the final links between objectives, methods, results and conclusions. For a clean passage, no comment is a valid outcome.

Illustrative comment shapes, not fixed templates:

- Reporting repair: “Add the confidence interval beside the coefficient, then use the same interval in the interpretation. Without it, the reader cannot judge the precision of the estimate.”
- Confirmed contradiction: “The objective concerns participation, but this question asks about access. Align both statements around the same construct and carry that terminology into the analysis.”
- Genuine uncertainty: “What does ‘regular use’ mean in this measure? State the recall period and response categories so that the score can be interpreted consistently.”

Do not treat automated variation metrics as proof of human review quality. A varied comment can still be wrong, and a brief repeated phrase can be appropriate. Confirm accuracy and usefulness before preferring a more fluent model.

Remaining limits: statistical checking is based on reported output, not raw-data reproduction. Bibliographic matching does not establish claim support. Scanned PDFs need OCR. Editable Word shapes and unsupported image formats may require manual visual verification. Bounded final audits record omitted evidence rather than claiming complete inspection. New or inaccessible model IDs still require API access and compatible capabilities.
